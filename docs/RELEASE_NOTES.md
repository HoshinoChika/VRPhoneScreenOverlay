# 0.2.8（候选，待验收）

软件内更新公告以 [0.2.8 公告原文](release-notes/0.2.8.txt) 为准；本轮待用户审阅，未激活公开更新。

- 新增 DeepSeek 辅助排障：结合用户描述、日志、现场检查和对应版本源码分析，只诊断、不改码或安装补丁；支持复现采集和历史记录。

- 改善连接与组件恢复，减少与其他 ADB 软件共用时的干扰。
- 改善视频解码、画质切换和旋转后的触摸处理，修正迟到旧帧覆盖新画面的边界问题。
- 核对各类手柄默认按键，改进浮窗唤回，并修正自定义触摸绑定的松手判断。
- 简化画面设置，仅保留“应用”和“取消”，隐藏普通界面中的内部调试说明。
- 完善异常、历史会话和输入诊断；诊断上传覆盖最近 6 小时，本地保留最近 24 小时。

通过软件内更新到此版时，会按之前确定的更新流程应用本版默认手柄绑定；更新完成后可以重新自定义，普通启动保留新自定义。首次从原版 0.2.7 更新仍由旧维护程序执行，其他 ADB 软件可能短暂受影响。

候选包仅用于验收，正式更新尚未激活。官网下载页当前仍展示已发布的 0.2.7，并提供固定版本下载与文件校验值。
