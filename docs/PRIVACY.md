# 诊断与隐私

## 截图翻译与内置 API

当前客户端提供截图翻译、答题和画面理解，不再提供旧版 DeepSeek 辅助诊断页面。只有用户主动发起识图时才采集对应 VR 画面并发送给 DeepSeek；手机持续投屏不经过该服务。

选择个人 API Key 时，Key 使用当前 Windows 用户的系统加密能力保存在本机，图片直接发给 DeepSeek。选择软件内置时，客户端只向本软件服务器发送临时公钥和随机校验值，领取短期加密凭据包；解密后在本次运行内存中复用 Key，图片仍直接发送给 DeepSeek，不经过本软件服务器。认证失效时最多重新领取并重试一次，不自动切换个人 Key。切换来源不会删除个人 Key。

内置 Key 不写入客户端配置或日志，但调用时会存在于进程内存，不能保证无法被本机调试器或内存转储提取。加密包过期不是 DeepSeek 原始 Key 的撤销。识图结果会作为本地文字历史保存；测试或故障检查中主动保存的截图应由用户自行管理。

VRChat 相册同步及截图传手机通过本机 ADB 连接完成，不上传到本软件服务器。普通剪贴板同步在本机处理；主动解析或开启自动解析视频链接时，相关网址会发送给解析服务。

## 普通诊断包

诊断包只在用户主动填写问题并提交时生成和上传，不在启动更新检查时上传。

软件运行期间会在本机保留有界的关键阶段记录；独立隐藏监控进程随主程序启动，观察其退出后结束，不安装系统服务。记录包括构建标识、随机会话编号、进程身份、正常结束标记、首帧阶段、实际解码/GPU 后端与尺寸、退出码；托管异常只保留类型、错误码和方法名堆栈，不保存异常消息中的任意用户数据。可读取与本次进程和时间相符的 Windows Application Error 事件，提取模块文件名、异常码及偏移；未找到或读取失败会明确标记，不把它当作无故障。异常或卡死等情况下可自动在本机保存有界内存诊断；不会自动上传。附带内存需要在每次诊断上传时单独选择，默认不附带。

本地每会话最多 64 条阶段记录，记录文件读取上限 128 KiB；通常保留最近 16 个会话，仍活动的会话不会被清理。提交时包含最近最多 8 个会话的独立摘要，因此重启后的 Stopped 状态不会覆盖上一会话。监控程序从安装目录校验复制到私有诊断目录运行，后续启动清理已结束会话的程序副本。这些本地记录不随心跳或更新检查上传。

诊断健康摘要包含日志接受、刷新、丢弃、拒绝、待刷新和写盘失败计数；最多 16 组错误码的首次/末次时间和次数。健康与监控存活样本每 2 秒更新，关键阶段另保存当时的健康及硬件摘要；样本不是每个瞬间的完整记录。手机、解码器、显卡、头显和手柄摘要区分当前状态与上次已知状态。启动时另读取系统/.NET 版本、架构、逻辑处理器数量及最多 16 个已安装显示驱动候选的描述、版本、厂商；候选列表不等于实际使用的显卡。

错误历史最多保留 8 份有界异常链，每链最多 8 个原因和每原因 8 个方法名，超出记录文件字节预算时提前淘汰较旧记录并统计。主错误和清理错误分别记录，每次媒体尝试有独立随机编号。日志收录会报告未读文件、尾部裁剪、无效行及输出截断；每文件最多输出 20,000 行或 5 MiB。无法采集的信息用状态说明，不以缺失信息证明没有异常。

包含：应用/OS/.NET 版本；运行状态和原因码；Android 型号/版本与连接类型；画面尺寸、帧率、码率、延迟、丢帧；音频缓冲和控制队列指标；空间拖拽状态；手柄绑定来源及可用性；白名单配置摘要；问题发生时间及说明；最近最多三个 Android 日志文件的末尾（每份最多 5 MiB）。更新失败类别包含在运行概要中；维护配置、服务主机和服务管理凭证不包含在运行概要中。

普通结构化日志不主动采集：手机截图、视频、录音、聊天内容、剪贴板内容、完整设备序列号、完整用户目录、配对码、密码、更新签名私钥、SSH 私钥或绑定文件原文。

若主动选择附带内存，内存文件可能包含手机内容片段、聊天文字、路径、API Key 或临时凭据，不能承诺按上述字段清单完全排除或脱敏。选择只对本次上传有效。

结构化字段与文本会做脱敏。用户自由填写的文本无法保证识别所有私人信息，因此请勿主动输入秘密或个人资料。诊断并非绝对不可关联的匿名数据；服务器连接本身会使用来源网络地址处理限流。

客户端诊断 ZIP 上限 544 MiB（含可选内存附件），临时授权仅用于一次限定大小的上传；只接受当前服务同源 HTTPS 上传地址。诊断包先保存在 VPS；按北京时间，每到新月份将上月的包汇总归档至作者私有的 115 网盘，不公开分享。成功归档后，VPS 按默认 14 天保留策略清理已过期的本地副本；归档失败时保留源文件。115 月归档不自动过期，由维护者管理。客户端成功上传后清理本地临时包；上传失败时保留完整包并后台移至软件根目录，提示联系作者。目录不可写时保留原位置并给出路径。

更新检查仅向新服务请求清单，不发送手机画面或诊断包。更新包在安装前验证清单签名、大小和 SHA256，安装后执行健康确认并保留回滚机制。

ADB 诊断包含服务端点的配置来源、地址类别、端口和配置指纹，目标设备使用既有序列号哈希，不保存完整序列号或服务地址。命令只记录白名单类别/子类别、耗时、退出码、超时阶段及原生错误码；失败时可附最多 800 字符的脱敏错误摘要，输入文本操作的错误正文直接省略。ADB 服务摘要保留版本、USB/mDNS 后端和可执行文件来源类别，不保留完整程序/日志路径，并注明采样时间。

固定 ADB 组件恢复前记录三个固定文件的相对名称、大小、预期/实际 SHA256、发布标识、恢复阶段及错误码，不包含文件正文或完整路径。本地各保留最近一份安装组件/运行副本恢复摘要；主动提交诊断时加入 component-recovery.json，每份读取上限 16 KiB，并区分未采集、读取失败和超限。

画面验证记录保存在本地，包含期望/实际应用参数、更改意图、首帧与稳定状态、构建标识、原生尺寸、解码模式及缓冲几何。设备键只参与生成范围哈希；记录不包含完整序列号、文件路径或画面内容。最多保留 8 个设备/尺寸/模式范围的成功档案、8 次最近尝试和 8 次最近更改，文件读取上限 128 KiB，省略数和后端名称截断会标记。主动提交诊断时将该快照及当前自动打开保护状态加入 settings-summary.json；不随心跳发送。损坏记录经用户确认重建时，最近一份原文件仅在本地保留，不自动上传。

## 使用人数统计

软件正常启动后默认发送使用心跳：首次延迟 5–15 秒，之后每 60 秒直连 HTTPS 一次，单次超时 5 秒。仅发送协议版本和随机安装标识，不发送账号、手机标识、硬件指纹、屏幕或操作内容。心跳与主动上传诊断相互独立。来源 IP 对网络服务可见，但不写入心跳统计数据；反向代理/主机自身日志由维护者另行管理。

随机标识保存于本机用户配置目录的 `usage-installation-id.txt`，不会随软件 ZIP 分发，也不包含在诊断包中。正常升级保留标识；更换 Windows 用户/电脑或清除该文件可能被算作新安装。同一标识的多个进程只计一个在线实例。因此统计是安装实例估算，不是自然人人数，也不代表用户持续操作。

服务端只保留标识的 SHA256、首次和最近收到心跳的服务器时间。为了累计去重，这些最小记录持续保留，管理员可删除统计数据重新开始计数。没有逐分钟行为历史。在线超时为 180 秒；活跃窗口为滚动 24 小时、7 天、30 天。每 60 秒原子保存一次，正常停止保存；异常断电可能丢失最后一分钟记录。

可在启动软件前设置用户环境变量 `VRPSO_USAGE_HEARTBEAT=0` 关闭心跳，重启生效；关闭不影响投屏、无线连接或更新。快照和冒烟测试不会启动心跳。

统计服务的新标识登记限流会临时使用来源网络地址的哈希，仅用于内存中的一小时限流窗口，窗口过期后下次登记时清理，容量有界，不写入累计统计文件。已有标识正常心跳不消耗新标识登记额度。统计文件损坏时不自动清零，而是停用统计等待维护；更新和诊断接口继续提供服务。
