# 使用教程

1. 电脑准备 SteamVR，解压完整软件目录。
2. 在手机上开启开发者选项。USB 方式开启 USB 调试并确认授权；无线方式开启无线调试，在其中使用扫码配对或配对码配对，按软件对应页面操作。电脑和手机需在同一局域网。
3. 手机就绪后打开浮窗；在“功能”页查看当前手柄与惯用手的按键说明。
4. 齿轮打开菜单，可隐藏浮窗、调整透明度和空间设置。无论浮窗当前显示还是隐藏，长按当前唤回键 2 秒都会显示手机并放回头显前方；默认是摇杆按下，具体按键以功能页为准。空间拖拽或离开较远距离不会自动隐藏浮窗。
5. 空间拖拽按需开启。惯性、重力、阻力实时生效并保存，总开关每次启动默认关闭。

## 更新

启动约 8 秒后检查一次，启动检查最多使用 20 秒，不循环轮询。手动检查位于“关于”。发现更新会显示版本、更新内容以及“更新 / 暂不更新”。只有点击“更新”才下载、校验并重启。不要在正在更新时移动程序文件。

无法在线升级的旧版本，请下载完整 ZIP，退出旧程序后运行解压后的新版。配置仍使用用户应用数据目录；升级前可自行备份该目录。

下一版通过软件内更新安装后，会直接覆盖本应用的旧 SteamVR 绑定为新版默认，需要重新设置自定义按键。不会迁移或保留旧绑定；其他应用的绑定和手机设置不变。普通启动不会反复重置更新后新建的自定义绑定。

“随 SteamVR 启动”会核对当前安装路径及开关读回。SteamVR 暂不可用时保留设置并有限重试，重新开启 SteamVR 后再核对。设置读取损坏时不会自动关闭 SteamVR 原有启动偏好，设置页会提示重新确认。移动软件目录后，需要先从新目录手动运行一次，才能更新启动登记；登记成功仍需实际重启 SteamVR 验证自动拉起。

## 常见问题

### DeepSeek 排障

新版会结合现场检查和与当前构建对应的软件源码分析。界面仍显示简短结论；详细的证据、代码位置和待确认问题保留在服务器，方便作者进一步排查。源码找不到或现场证据不足时会保留未知，不会把推测当成已经修好，也不会自动修改或编译软件代码。

AI会根据问题自主选择运行状态、配置摘要、近期日志、源码或文件检查，不要求每次先查手机连接。检查不会擅自覆盖设置；未采集的实际体验仍需要你确认。

在“关于”打开问题诊断包上传表单，选择问题类型并填写现象描述，左下角的“使用DeepSeek排查故障”按钮才会启用。点击后先上传诊断包；成功后自动进入“DeepSeek故障诊断”页面并开始诊断。普通“开始上传”仍只上传诊断包。

新诊断只能通过上传表单中的“使用DeepSeek排查故障”发起。表单另有“查看AI诊断历史”，无需填写或上传，查看历史不会再次调用 AI。诊断页按钮下方显示所选记录的完整信息；选择一条历史记录可查看完整分析、执行情况和反馈。下方历史仅显示时间、用户填写的故障描述及结果；故障描述超过十个字时显示前十个字加省略号，鼠标悬停不会弹出全文。选中记录后可点击上方“已修复/没修好”反馈，或刷新历史、返回填写页。进行中返回会停止后续排障，完成必要收尾后保留已填内容。

诊断由DeepSeek决定下一项检查，也能独立查询相关源码。需要重现故障时，按AI提示准备好后点击“开始复现采集”，在20秒内操作；也可跳过或返回取消。最多进行六轮本地检查，只诊断、不自动修改配置或执行修复。历史保留每轮经过，详细源码调查另存服务器，方便作者接手。请根据后续实际体验反馈问题是否解决。

诊断前会先确认服务是否可用；次数不足或仍需等待时，会在上传表单中说明。复现采集期间可以切换到主页进行正常操作，点击“关于”可返回正在进行的诊断。分析中断时会明确提示，并保留已经采集的记录，不把准备步骤当作最终结论。

诊断结论为绿色；需要你操作的内容为橙色加粗，“开始复现采集”按钮同色；跳过提示及按钮为浅蓝色；明确的检查失败等使用红色。

纯粹测试接口或与本软件排障无关的输入只会得到简短回复，不检查手机或执行修复。若实际遇到黑屏、连接失败或 AI 服务报错，请写明现象，即使描述中包含“测试”也会正常排查。

### 其他问题



手机平台条件、PC 串流与手柄家族的验证范围见 [兼容条件与检查结果](COMPATIBILITY.md)。软件仿真和默认按键配置不代表每个实际型号均已通过硬件验收。

- 无线未连接：点亮手机，检查无线调试和同一局域网，再刷新。软件会尝试上一次成功地址，端口变化时需重新发现；手动断开会清除自动重连地址。
- 无声音：确认 Android 版本、音频权限与应用是否允许内部音频采集。
- 按键不符：确认惯用手，查看“功能”中的实际绑定说明；不要覆盖自己的 SteamVR 绑定文件。
- 手机触摸无反应：主页控制流若显示“权限受限 ?”，点击可查看手机明确拒绝注入后的处理说明。部分 Xiaomi/Redmi 需要额外开启“USB 调试（安全设置）”并重启手机，无线连接也适用。没有这条提示不能排除权限问题；请分别对照本应用菜单、手机亮屏的系统设置页滚动，并上传诊断。“已发送”只表示写入控制通道，不是手机已执行的回执。
- 更新服务器暂无版本：表示该通道尚未激活公开清单，不等于网络连接失败。
- 反馈问题：选择类型、发生时间，简要描述现象后主动上传诊断。不要填写密码、配对码或个人信息。

### DeepSeek 辅助排障

在“关于”的问题诊断上传页面，选择问题类型并填写现象，点击“使用DeepSeek排查故障”。软件先上传诊断包，再自动开始诊断。AI 会根据描述选择现场检查并参考对应版本源码；需要复现时按提示操作，也可以跳过。历史记录可单独查看。

AI 只提供诊断和建议，不修改代码或安装补丁。建议仍需结合实际效果判断；证据不足不等于软件正常。请不要在描述中填写密码、验证码或其他私人信息。返回会停止当前排查，已经取得的记录会保留。

### 软件解码对照

排查无画面或解码失败时，可先退出程序，再在软件目录的普通 PowerShell 窗口运行 `./VRPhoneScreenOverlay.exe --software-decoder`。这次启动会跳过硬件解码器候选，用软件后端进行对照；画质、绑定和手机设置不变。关闭后正常启动即可恢复自动选择。软件后端可能增加 CPU 占用，能出图也不等于硬件故障已修复，请在反馈中注明使用了该参数。

### 画面设置

在画面页调整分辨率、码率和帧率，点击“应用”保存修改。浮窗正在运行时会按新设置刷新画面；未打开时，在下次打开浮窗时使用。

点击“取消”撤回本次尚未应用的修改，不影响已经保存的设置。如果画面启动失败或程序异常关闭，回到主页手动开启浮窗即可重试，无需另外确认恢复设置。实际保存或启动失败时，界面会显示操作提示。
