# 使用教程

1. 电脑准备 SteamVR，解压完整软件目录。
2. 在手机上开启开发者选项。USB 方式开启 USB 调试并确认授权；无线方式开启无线调试，在其中使用扫码配对或配对码配对，按软件对应页面操作。电脑和手机需在同一局域网。
3. 手机就绪后打开浮窗；在“功能”页查看当前手柄与惯用手的按键说明。
4. 齿轮打开菜单，可隐藏浮窗、调整透明度和空间设置。隐藏后按当前唤回键长按，具体按键以功能页为准。
5. 空间拖拽按需开启。惯性、重力、阻力实时生效并保存，总开关每次启动默认关闭。

## 更新

启动约 8 秒后检查一次，启动检查最多使用 20 秒，不循环轮询。手动检查位于“关于”。发现更新会显示版本、更新内容以及“更新 / 暂不更新”。只有点击“更新”才下载、校验并重启。不要在正在更新时移动程序文件。

无法在线升级的旧版本，请下载完整 ZIP，退出旧程序后运行解压后的新版。配置仍使用用户应用数据目录；升级前可自行备份该目录。

## 常见问题

手机平台条件、PC 串流与手柄家族的验证范围见 [兼容条件与检查结果](COMPATIBILITY.md)。软件仿真和默认按键配置不代表每个实际型号均已通过硬件验收。

- 无线未连接：点亮手机，检查无线调试和同一局域网，再刷新。软件会尝试上一次成功地址，端口变化时需重新发现；手动断开会清除自动重连地址。
- 无声音：确认 Android 版本、音频权限与应用是否允许内部音频采集。
- 按键不符：确认惯用手，查看“功能”中的实际绑定说明；不要覆盖自己的 SteamVR 绑定文件。
- 更新服务器暂无版本：表示该通道尚未激活公开清单，不等于网络连接失败。
- 反馈问题：选择类型、发生时间，简要描述现象后主动上传诊断。不要填写密码、配对码或个人信息。
